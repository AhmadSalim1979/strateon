## 2. What Is Changing in the World

**The enterprise AI market is splitting into two distinct segments with different competitive dynamics.**
Segment 1: AI augmentation — copilots, assistants, productivity tools. This market is commoditizing rapidly. ## 6. AI Agent Capability Watch

### What's Improving Rapidly

**Long-horizon agentic task completion** — Claude 4.2's 23% improvement on multi-step tasks closes the practical gap with OpenAI's agent modes for complex enterprise workflows. This is the highest-value improvement because it unlocks AI use cases that require sustained context and multi-step reasoning.

**Tool-use reliability** — Function calling APIs across Anthropic, OpenAI, and Google have stabilized significantly. The "model doesn't use tools correctly" failure mode is becoming less common. Remaining failures are mostly edge cases and novel tool configurations.

**On-device agentic capability** — Gemma 4 powering fully on-device workflows is now shipping in enterprise-managed contexts. Privacy-sensitive, latency-critical, and data-residency-restricted workflows now have a fully agentic solution. This is the compliance answer for regulated industries.

### What's Still Weak

**Real-time information access** — All frontier models still struggle with real-time data. Google Deep Research is the best workaround but is slow and sometimes produces hallucinated recent events. Native real-time web access remains unreliable. This is a fundamental limitation that model improvements alone won't fix without architectural changes.

**Long-tail task generalization** — Agents perform excellently on common task patterns but degrade significantly on unusual edge cases. The "last 10%" of task coverage requires disproportionately more capability. In enterprise contexts, those edge cases are often the high-value, high-risk decisions.

**Reliable autonomous decision-making with full auditability** — Agent systems can make decisions, but the explainability and auditability for regulated industries remains a significant gap. The accountability frameworks don't exist for autonomous AI to make final consequential decisions in financial services, healthcare, or legal contexts.

### Where Real Leverage Is

**Research synthesis** — Google Deep Research at 10M daily queries with 18-minute sessions demonstrates that AI-powered research is now a primary use case. The leverage is in replacing traditional research analyst workflows for any task that requires synthesizing information from many sources.

**Document-heavy workflows** — Legal document review, financial report analysis, contract extraction — these are the highest-ROI agent applications because labor cost is high, volume is high, and the task is pattern-based.

**Software development assistance** — Agentic coding assistants (GitHub Copilot, Cursor, Claude Code) are demonstrably increasing developer productivity. The leverage is in boilerplate generation, test writing, code review, and documentation — not in novel architecture design.

### Where Hype Exceeds Reality

**Fully autonomous AI employees** — The fantasy of "hire an AI agent and let it run a department" is not close to reality. Current agents are excellent at specific, bounded tasks. They fail catastrophically at ambiguous instructions, novel situations, and tasks requiring institutional knowledge.

**AI strategic decision-making** — No current AI system can replace human strategic judgment. AI can synthesize information, model scenarios, and recommend options. It cannot make decisions under genuine uncertainty with incomplete information and stakeholder complexity.

**AI creativity beyond patterns** — AI generates excellent variations on existing creative patterns. It cannot genuinely innovate beyond its training distribution. AI-assisted creative work is powerful; AI-generated creativity is remix.

### Capability Convergence Signals

**Tool calling standardization** — Anthropic A2A, OpenAI Agent SDK, and Google Agent Skills are converging on similar tool-use and multi-agent communication protocols. Within 18-24 months, agents from different providers should be interoperable at the protocol level.

**Evaluation benchmark consolidation** — The proliferation of AI benchmarks is consolidating around a smaller set of widely accepted measures (MMLU, HumanEval, and agentic benchmarks). This makes model comparison more reliable and reduces the "benchmark shopping" problem.

4. **Vertical agent platforms with domain training and regulatory moats** — Legal, medical, and financial agents genuinely trained on domain-specific data with domain-specific evaluation metrics are rare. Most "AI for law/medicine/finance" are general models with a thin domain wrapper.
