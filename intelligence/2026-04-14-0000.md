## 6. AI Agent Capability Watch

### What's Improving Rapidly

**Long-horizon agentic task completion** — Claude 4.2's multi-step agentic improvement (from prior report) closes the practical gap with OpenAI's agent modes for complex enterprise workflows. Sustained context and multi-step reasoning are now enterprise-competitive capabilities.

**Tool-use reliability** — Function calling APIs across Anthropic, OpenAI, and Google have stabilized significantly. The "model doesn't use tools correctly" failure mode is becoming less common. Remaining failures are mostly edge cases and novel tool configurations.

**On-device agentic capability** — Gemma 4 powering fully on-device workflows is now shipping in enterprise-managed contexts. Privacy-sensitive, latency-critical, and data-residency-restricted workflows have a fully agentic solution.

### What's Still Weak

**Real-time information access** — All frontier models still struggle with real-time data. Google Deep Research is the best workaround but is slow and sometimes produces hallucinated recent events. Native real-time web access remains unreliable. This is a fundamental limitation that model improvements alone won't fix without architectural changes.

**Long-tail task generalization** — Agents perform excellently on common task patterns but degrade significantly on unusual edge cases. The "last 10%" of task coverage requires disproportionately more capability. In enterprise contexts, those edge cases are often the high-value, high-risk decisions.

**Reliable autonomous decision-making with full auditability** — Agent systems can make decisions, but the explainability and auditability for regulated industries remains a significant gap. The accountability frameworks don't exist for autonomous AI to make final consequential decisions in financial services, healthcare, or legal contexts.

### Where Real Leverage Is

**Research synthesis** — AI-powered research is now a primary use case replacing traditional analyst workflows. Tasks requiring synthesizing information from many sources are high-ROI agent applications.

**Document-heavy workflows** — Legal document review, financial report analysis, contract extraction — high labor cost, high volume, pattern-based. These are the highest-ROI agent applications.

**Software development assistance** — Agentic coding assistants demonstrably increase developer productivity. The leverage is in boilerplate generation, test writing, code review, and documentation — not in novel architecture design.

### Where Hype Exceeds Reality

**Fully autonomous AI employees** — The fantasy of "hire an AI agent and let it run a department" is not close to reality. Current agents are excellent at specific, bounded tasks. They fail catastrophically at ambiguous instructions, novel situations, and tasks requiring institutional knowledge.

**AI strategic decision-making** — No current AI system can replace human strategic judgment. AI can synthesize information, model scenarios, and recommend options. It cannot make decisions under genuine uncertainty with incomplete information and stakeholder complexity.

**AI creativity beyond remix patterns** — AI generates excellent variations on existing creative patterns. It cannot genuinely innovate beyond its training distribution.
