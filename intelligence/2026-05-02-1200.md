## AI Agent Capability Watch

### What's Improving Fast
- **Long-horizon task completion:** Agents can now hold context and execute multi-step tasks over hours/days rather than minutes. Not fully reliable but dramatically better than 6 months ago.
- **Code generation and debugging:** Code agents (Devin, Claude Computer Use, GitHub Copilot) are now writing production-quality code in controlled environments. Error rates dropping.
- **Research synthesis:** Ability to read, synthesize, and synthesize across 100+ document sources is now commodity. What was a PhD-level research task 18 months ago is now a 2-minute agent task.
- **Multi-modal understanding:** Vision + language + audio understanding converging. Agents can now interpret screenshots, diagrams, and video with high accuracy.

### What's Still Weak
- **Real-time physical world interaction:** Agents fail when dealing with ambiguous physical tasks or environments that change dynamically. The "last mile" of physical AI remains unsolved.
- **Context preservation across sessions:** Long-term memory and identity persistence across sessions is still unreliable. Most agents reset on each conversation.
- **Calibration on low-confidence tasks:** Agents still hallucinate with high confidence on topics they know little about. Poor uncertainty representation.
- **Cross-domain generalization without fine-tuning:** Agents trained on one domain (legal) don't transfer well to adjacent domains (financial) without significant retraining.

### Where Real Leverage Is
- **Structured data extraction and transformation:** Anything where input is messy and output needs to be clean. Forms processing, document parsing, data cleaning.
- **Research and analysis at scale:** When you need 50 sources synthesized, agents win. Human would take weeks, agent does it in minutes.
- **Automated customer communication:** Respond, follow up, escalate — when the decision tree is complex enough that scripted chatbots fail.
- **Software code review and security auditing:** Finding bugs, vulnerabilities, and architectural problems at scale.

### Where Hype Exceeds Reality
- **Fully autonomous agents in regulated professions:** Legal and medical AI agents still require human oversight. The "AI lawyer" narrative is 5+ years from reality in court-adjacent contexts.
- **General robotics:** Boston Dynamics and Physical AI labs are making progress but humanoid robots in unstructured environments is a 10-year timeline, not 2 years as some pitch decks claim.
- **AI strategy and judgment:** Agents are great at executing known playbooks, not at figuring out which playbook to use in novel situations. Strategic reasoning remains human.

### Capability Convergence Signals
The top 5 model providers (OpenAI, Anthropic, Google, Meta, MiniMax) are all within 5% of each other on core benchmarks. This signals:
1. The "raw intelligence" gap is closing
2. Differentiation moving to cost, speed, and use-case specialization
