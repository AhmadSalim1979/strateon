## 6. AI Agent Capability Watch

### What's Improving Fast
- **Tool use and function calling** — LLM tool use is now reliable enough for production. Agents can use browsers, code interpreters, APIs, and file systems with high accuracy.
- **Context window and memory** — 1M+ token contexts are becoming standard. Long-horizon task completion is improving.
- **Multi-step reasoning** — Extended thinking models (o3, Gemini 2.5) show strong chain-of-thought reasoning across complex, multi-step problems.
- **Code generation and debugging** — Autonomous debugging success rates are climbing (65-70% for common bugs). Test generation is strong.

### What's Still Weak
- **Real-time information** — LLMs still hallucinate or don't know recent events. Retrieval augmentation helps but isn't perfect.
- **Complex multi-agent coordination** — Orchestrating 3+ agents reliably is still hard. Communication protocols, shared state, and conflict resolution are immature.
- **Ambiguity tolerance** — Agents still struggle with underspecified requests. Human clarification remains necessary in many cases.
- **Long-horizon planning with contingencies** — Agents can plan 5-10 steps but struggle with plans that require adaptation mid-execution.
- **Cost control** — Agentic loops (where the agent calls itself multiple times) can burn tokens quickly. Budget management is still manual.

### Where Real Leverage Is
- **Structured data extraction** — PDFs, forms, images → structured data. Much cheaper than human data entry.
- **Automated reporting** — Pulling data, summarizing, formatting. High value for recurring business intelligence.
- **Code refactoring and test generation** — Developers save 20-30% time on routine coding tasks.
- **Customer service triage** — Routing, initial response, FAQ resolution. Escalation to humans for complex issues.
- **Research synthesis** — Web search + summarization + citation. Good for market intelligence and competitive analysis.

### Where Hype Exceeds Reality
- **Fully autonomous agents** — "Set it and forget it" AI agents don't exist reliably in production for complex workflows. Human oversight remains necessary.
- **AGI proximity claims** — Every new model release is called "AGI-level" by some. The reality is incremental improvement on specific tasks, not general intelligence.
- **AI agents replacing jobs** — The narrative of mass job displacement is overblown. AI automates specific tasks, not entire job functions. New roles are being created alongside displaced ones.
- **Zero-shot reliability** — Models that "just work" without domain fine-tuning or careful prompt engineering. In practice, production deployment requires significant customization.

### Capability Convergence Signals
- **Standard feature set emerging** — Every major agent framework is converging on: tool use, memory, human-in-loop, multi-agent, evaluation. The differentiation is implementation quality and UX.
- **Benchmarks becoming saturated** — MMLU, HumanEval, and other benchmarks are reaching ceiling performance. New evaluation paradigms (agentic benchmarks, real-world task evals) are needed.
- **Fine-tuning democratization** — LoRA, QLoRA, and fine-tuning-as-a-service are making domain-specific models accessible to smaller teams. Custom models are no longer just for big tech.
