**root cause identified:** The Formspree webhook handler sets `replyTo: 'ahmad.salim@qiyadon.com'` on line 244 of `server.js`. The SMTP server rejects this because the authenticated sender is `contact@qiyadon.com` — the reply-to address must be owned by the authenticated user.

**Impact:** This causes mail failures for the Formspree webhook path only. The old `/submit-audit` path uses `creds.user` as `from` (contact@qiyadon.com) and is not affected.

**Fix needed:** Change line 244 in `server.js` from:
```javascript
replyTo: 'ahmad.salim@qiyadon.com',
```
to:
```javascript
replyTo: 'contact@qiyadon.com',
```
Or remove `replyTo` entirely.
