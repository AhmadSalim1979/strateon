## 🔴 Critical Bug — Email replyTo Mismatch

**Bug:** `553 5.7.1 <ahmad.salim@qiyadon.com>: Sender address rejected: not owned by user contact@qiyadon.com`

**Symptom:** Audit form submissions fail to send email — SMTP rejects sender address.

**Location:** `server.js`, `/submit-audit` handler, line ~284

**Root cause:** `replyTo` field set to `ahmad.salim@qiyadon.com` but SMTP authentication uses `contact@qiyadon.com`. The SMTP server rejects sending from an address that doesn't match the authenticated user.

**Fix:** In `server.js` `/submit-audit` handler, change `replyTo` from `ahmad.salim@qiyadon.com` to `contact@qiyadon.com`. One-line change.

**Status:** 🟡 PENDING — identified but not applied as of 2026-05-05
**Status Update (May 9):** Still pending. No evidence of fix applied. Carried forward.

**Why it matters:** Every audit form submission currently fails to send the follow-up email to the prospect. This is a direct revenue impact. Fix takes 2 minutes.
