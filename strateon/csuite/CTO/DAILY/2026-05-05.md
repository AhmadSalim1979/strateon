### 2. Deployment Documentation Draft

**Current deployment steps (for documentation):**

#### Deploy website updates:
1. Edit files in `strateon-site/` directory
2. `git add . && git commit -m "description"`
3. `git push origin` (from strateon-site submodule)
4. Netlify auto-detects push → builds and deploys within ~1-2 minutes
5. Check qiyadon.com for updated content

#### Deploy Cloudflare Worker updates:
1. Edit Worker script in `cloudflare-workers/` directory
2. Deploy via: `wrangler deploy` or direct Cloudflare API call

#### Restart PM2 services:
1. `pm2 list` — check process status
