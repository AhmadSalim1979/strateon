## Email Bug — Identified but Not Fixed

**Bug:** `553 5.7.1 <ahmad.salim@qiyadon.com>: Sender address rejected: not owned by user contact@qiyadon.com`

**Location:** `server.js` — `/submit-audit` email handler (Forms path)

**Root cause:** Line ~244 sets `replyTo: 'ahmad.salim@qiyadon.com'` but SMTP auth is `contact@qiyadon.com`. When the Formspree relay emails are processed and the server tries to reply from ahmad.salim, the SMTP server rejects it.

**Fix:** One-line change — change `replyTo` from `ahmad.salim@qiyadon.com` to `contact@qiyadon.com` in the `/submit-audit` handler.

**Status:** Identified on 2026-05-07 by CTO morning session, but fix not yet applied.
