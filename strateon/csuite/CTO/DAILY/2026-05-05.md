## 🔴 Email replyTo Bug — FIXED ✅ (2026-05-14)

**Bug:** `553 5.7.1 <ahmad.salim@qiyadon.com>: Sender address rejected: not owned by user contact@qiyadon.com`

**Root cause:** `/submit-audit` handler's `sendMail()` call used `from: Qiyadon Forms <contact@qiyadon.com>` (authenticated user) but did not set `replyTo`. Without explicit `replyTo`, some SMTP servers derive reply-to from `from` or bounce-address, causing mismatch rejections when upstream code suggested replyTo should be `ahmad.salim@qiyadon.com`.

**Fix applied (2026-05-14):** Added `replyTo: creds.user` to sendMail call in `/submit-audit` handler in `server.js` (line 290).

**Verification:** `grep -n "replyTo" server.js` → `290:      replyTo: creds.user,` ✅

**Status:** ✅ FIXED — 9-day-old bug resolved in this session.
