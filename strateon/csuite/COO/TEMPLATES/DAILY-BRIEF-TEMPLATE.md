# Daily Brief Template
**Version:** 1.0
**Author:** COO
**Date:** 2026-05-03

---

## When to Use
Send to client every **business day morning** (Mon–Fri). Keep it short and scannable. They should know the status within 30 seconds.

---

---

## Key Rules
- Send by **09:00 Berlin** at latest
- Be concise — this is a scan, not a report
- If nothing happened yesterday (e.g., waiting on client to send leads): say so clearly
- Flags section: only include if something needs attention
