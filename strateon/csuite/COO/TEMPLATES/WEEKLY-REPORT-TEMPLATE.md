## Key Rules
- Send by **Friday 17:00** at latest
- If no hot leads this week: state clearly "No hot leads this week — all leads remain in follow-up sequence"
- If no stalled leads: state "No stalled leads this week — all on track"
- If decisions needed: be specific about what's needed and by when
