# Lead Submission Form Template
**Version:** 1.0
**Author:** COO
**Date:** 2026-05-03

---

## Purpose
Give clients a structured way to submit leads. This is the form they use to send you new leads throughout the engagement.

---

## Lead Submission Format

Submit leads using this format (one lead per row if spreadsheet, one per entry if other format):

| Field | Required | Notes |
|---|---|---|
| **First Name** | ✅ | |
| **Last Name** | ✅ | |
| **Company** | ✅ | |
| **Email** | ✅ | |
| **Phone (WhatsApp preferred)** | ✅ | Include country code |
| **LinkedIn URL** | Optional | |
| **Job Title** | Optional | |
| **Company Website** | Optional | |
| **Score** (Hot/Warm/Cold) | Optional | Client can pre-score; leave blank for COO to score |
| **Source** | Optional | Where did this lead come from? |
| **Notes** | Optional | Any context about this lead |

---

## Minimum Viable Lead Submission
If client can only provide: **Name + Company + Email** — that's enough. We can find the rest.

---

## Submission Instructions to Client
```
You can send us leads in any format:
• Spreadsheet (Google Sheets / Excel) — easiest for us
• Copy/paste from your CRM
• Even a WhatsApp message with name + company + email works

Minimum required: Name + Company + Email
We'll handle the rest.

New leads will be ingested within 2 hours of receipt and you'll receive a confirmation.
```

---

## What Happens After Submission
1. COO receives leads → acknowledges within 2 hours
2. Each lead gets scored (Hot 8–10 / Warm 5–7 / Cold 1–4)
3. Each lead gets a status: NEW → CONTACTED → FOLLOWING UP / HOT / STALLED
4. Client receives confirmation: "✅ Received [X] leads. [Y] scored hot, [Z] warm, [W] cold."
5. Follow-up sequence begins per cadence
