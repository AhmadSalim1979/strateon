## 🎨 Brand Color Palette (Canonical Reference)

| Role | Name | Hex | Usage |
|---|---|---|---|
| Primary | Deep Navy | `#0B1F3A` | Logo, headings, dark backgrounds |
| Secondary | Electric Teal | `#00C2CB` | Accents, highlights, CTAs |
| Accent | Warm Gold | `#F5A623` | Premium callouts, special emphasis |
| Light BG | Cloud White | `#F4F7FA` | Section backgrounds, cards |
| Text Primary | Charcoal | `#1A2B3C` | Body text |
| Text Secondary | Slate | `#6B7C93` | Captions, secondary text |
| Success | Signal Green | `#27AE60` | Positive indicators |
| Danger | Alert Red | `#E74C3C` | Errors, warnings |

> **CMO Note:** These colors must be consistent across ALL generated assets. Do not substitute or approximate.

## PRODUCTION NOTES

### General
- All assets should be delivered as PNG at minimum 2x display resolution
- SVG/vector preferred wherever possible for logo, icon, and flat graphics
- All text in generated images should be verified — AI image generators are unreliable with text; plan for a graphic designer to overlay confirmed copy in post

### Color Consistency
- Never deviate from the canonical hex palette above
- If a color match tool reads below 95% accuracy, regenerate or correct in post
- The Electric Teal `#00C2CB` is the brand's "action color" — use it sparingly but purposefully

### Text in Images
- AI image generators are NOT reliable at rendering readable text
- For ANY asset that includes words, plan for: generate visual → designer overlays confirmed text
- Exception: logo wordmarks are acceptable as-is IF the font rendering is clean
