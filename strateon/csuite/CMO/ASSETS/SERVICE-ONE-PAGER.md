### DESCRIPTION

A single-page (A4 / US Letter) document that communicates Strateon's core service offering, key value propositions, target industries, and a call to action. Designed for distribution in investor meetings, client pitches, and trade events.

**Content sections:**
1. Header: Strateon logo (horizontal lockup) + tagline
2. Hero statement: What Strateon does in one sentence
3. Service overview: 3–4 bullet points on core capabilities
4. Target industries: Icons + short labels
5. Why Strateon: 3 key differentiators
6. CTA: Contact information + QR code to website
