## 🎨 COLOR SYSTEM

### Primary Colors

| Color Name | Hex Code | Use |
|------------|----------|-----|
| Strateon Navy | `#0A1628` | Primary backgrounds, headers, dominance |
| Strateon Electric Blue | `#2563EB` | CTAs, links, highlights, accents |
| Strateon White | `#FFFFFF` | Reversed text, clean space |
| Strateon Off-White | `#F8FAFC` | Light backgrounds, cards |

### Secondary / Accent Colors

| Color Name | Hex Code | Use |
|------------|----------|-----|
| Strateon Gold | `#F59E0B` | Premium accents, badges, stars |
| Strateon Slate | `#64748B` | Body text on light, subtitles |
| Strateon Border | `#E2E8F0` | Dividers, card borders |
| Strateon Dark Slate | `#1E293B` | Secondary dark backgrounds |

### Color Don'ts
- Never use `#2563EB` (Electric Blue) as a large background block — it overwhelms. Reserve for accents and CTAs.
- Never place `#F59E0B` (Gold) next to `#F8FAFC` (Off-White) for large areas — contrast fails.
- Never invert the navy and electric blue roles — navy is primary, blue is accent.

## ✏️ TYPOGRAPHY SYSTEM

### Font Families
- **Display / Headlines:** Inter (700, 800) — sharp, modern, tech-forward
- **Body:** Inter (400, 500) — clean readability
- **Accent / Labels:** Inter (600) — uppercase tracking for small labels

### Type Scale

| Level | Font | Weight | Size | Line Height | Use |
|-------|------|--------|------|-------------|-----|
| H1 | Inter | 800 | 56px | 1.1 | Hero headlines |
| H2 | Inter | 700 | 40px | 1.2 | Section headers |
| H3 | Inter | 700 | 28px | 1.3 | Sub-section headers |
| H4 | Inter | 600 | 20px | 1.4 | Card titles |
| Body | Inter | 400 | 16px | 1.6 | Body copy |
| Caption | Inter | 500 | 13px | 1.4 | Labels, captions |
| Overline | Inter | 600 | 11px | 1.2 | Uppercase labels, tracking 0.1em |

### Typography Rules
- Always use Inter from Google Fonts or a locally loaded version.
- Never use: Times New Roman, Arial, Comic Sans, Papyrus.
- Letter spacing: Headlines should be tight (-0.02em to -0.03em). Labels should be tracked (+0.08em to +0.12em).
- Minimum body text size: 15px. Never go below 13px.

## 📐 SPACING SYSTEM

### Base Unit: 4px

All spacing is a multiple of 4px:

| Token | Value | Use |
|-------|-------|-----|
| `--space-1` | 4px | Tight gaps, icon padding |
| `--space-2` | 8px | Component internal padding |
| `--space-3` | 12px | Small gaps |
| `--space-4` | 16px | Standard padding |
| `--space-5` | 20px | Card padding |
| `--space-6` | 24px | Section internal |
| `--space-8` | 32px | Section gaps |
| `--space-10` | 40px | Large section gaps |
| `--space-12` | 48px | Hero spacing |
| `--space-16` | 64px | Major section dividers |

### Border Radius
- **Pills / Tags:** 999px (fully rounded)
- **Cards:** 12px
- **Buttons:** 8px
- **Input fields:** 8px
- **Modals:** 16px

## 🖼️ ICONOGRAPHY RULES

### Style
- Use **Lucide Icons** or **Phosphor Icons** (both free, open-source) as the primary icon library.
- Never mix icon libraries within a single product or presentation.
- Stroke weight: 1.5px–2px for standard use.
- Size: 16px (inline), 20px (buttons), 24px (cards), 32px+ (feature icons).

### Do Not Use
- Font Awesome (too generic, overused)
- Glyphicons (dated)
- Custom handmade icons unless explicitly approved by CMO

### Favicon / App Icon
- Design must work at 16×16px, 32×32px, 180×180px (Apple Touch), 192×192px (Android).
- Must be a simplified, single-color or two-color mark — NOT the full logo lockup.
- See: `ICON-FAVICON.md` for the approved V3 version.

## 🔤 LOGOTYPE RULES

### Primary Logo (Horizontal Lockup)
- The full wordmark "STRATEON" in Inter 800, with the tagline beneath or adjacent.
- Minimum clear space: 1× the cap height on all sides.
- Minimum size: 120px wide for digital, 30mm for print.
- Never stretch, skew, recolor, or add effects to the logo.
- See: `LOGO-PRIMARY.md` for V2 approved spec.

### Icon-Only Mark
- The standalone icon (not the full wordmark) may only be used at 40px or below.
- Acceptable contexts: App icons, favicons, tiny social profile images, favicons.
- NOT acceptable: business cards, letterhead, pitch decks — use the full lockup there.
- See: `ICON-FAVICON.md` for V3 approved spec.

## 📱 DIGITAL APPLICATION RULES

### Website / App
- Primary background: `#0A1628` (Navy) or `#FFFFFF` (White) — never light gray backgrounds.
- Accent buttons: `#2563EB` (Electric Blue) with white text.
- Text on dark: `#FFFFFF` or `#F8FAFC`. Text on light: `#0A1628` or `#64748B`.
- Card backgrounds: `#F8FAFC` (light) or `#1E293B` (dark).

### Social Media
- Profile image: Always the Icon-Only mark on a solid background. NOT the full horizontal logo.
- Banner images: See `LINKEDIN-BANNER.md`.
- Post cards: Maintain at least 16px padding from edges.

### Presentations (Pitch Deck)
- Dark backgrounds preferred (`#0A1628`).
- Use the horizontal logo lockup in the footer of every slide.
- Never use more than 3 colors from the palette in a single slide.
- See: `PITCH-DECK.md`.
