### DESCRIPTION

The official Strateon profile picture / avatar for all social media platforms. This is the **Icon mark** (V3 favicon) displayed on a solid Navy (`#0A1628`) square background. It is NOT the full horizontal logo — that doesn't work at small circular crops.

**Design:**
- Background: Solid Navy (`#0A1628`), square
- Mark: The V3 Icon mark centered, Electric Blue (`#2563EB`)
- No text, no tagline

### USAGE RULES

**✅ DO:**
- Use as the profile picture for Strateon's LinkedIn Company Page.
- Use as the profile picture for Strateon's Twitter/X account.
- Use as the profile picture for Strateon's Instagram Business account.
- Use for Facebook Page profile picture.
- Resize the same source image to platform-specific dimensions.

**❌ DO NOT:**
- Use the horizontal wordmark as a profile picture — it's illegible at small sizes.
- Add a white ring/border unless it's part of the approved design.
- Use V1 or V2 of the icon — only V3 is approved.
- Add text overlays to the profile image.
