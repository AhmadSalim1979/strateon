### DESCRIPTION

A 3D-rendered mockup of the Strateon product (mobile app or web dashboard) displayed on a floating device (iPhone-style or generic smartphone) against a Navy background with subtle ambient lighting. Used for:

- Website hero sections
- Pitch deck "product" slides
- Press kit visuals
- Social media posts

**Design:**
- Device: Light silver/white smartphone with thin bezels
- Screen: Strateon app interface (navy + blue theme)
- Background: Navy (`#0A1628`) with subtle blue glow
- Angle: Slightly tilted, floating appearance

### USAGE RULES

**✅ DO:**
- Use on the website hero section above the fold.
- Use as the "Product" visual in pitch decks.
- Use in press releases and media kits.
- Display on dark-background landing pages.

**❌ DO NOT:**
- Use with a white or light background — the device blends in.
- Add text overlays or arrows pointing to UI elements unless in a tutorial context.
- Modify the device or screen design.
- Use in isolation without the navy background context unless the PNG has a transparent bg.
