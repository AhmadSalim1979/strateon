## Today's Objective — Response Webhook

### Problem
The Follow-Up Engine sends emails on a cadence. When a lead replies, the engine should stop the cadence (lead is alive — no more auto-follow-ups). Currently the engine cannot detect replies — it has no webhook to receive them.

### Solution
Build a POST endpoint `/followup-response` that:
1. Receives an email reply notification (from SMTP pipe or a simple form)
2. Looks up the contact by email address in HubSpot
3. Sets `strtn_response_received: yes` on the contact
4. Logs the response event

This closes the loop: engine sends → lead replies → webhook marks contact alive → engine skips future cadence steps.

### What I Did This Session

**Built:** `strateon/followup-engine/response-webhook.js`

An Express.js HTTP endpoint that:
- Accepts POST `/followup-response` with `{ email, subject, snippet }`
- Fetches contact from HubSpot by email (CRM API v3 search)
- Updates `strtn_response_received: yes` on the contact
- Logs the event to the daily log file
- Returns `{ success: true, contact: email }` or error detail

**Syntax check passed** ✅

**File:** `strateon/followup-engine/response-webhook.js` — ~100 lines, minimal Express + HubSpot API v3

## HubSpot Custom Properties — Exact List for Ahmad

**These 6 properties must be created in HubSpot before any client can use the engine.**

Create in HubSpot: Settings → Properties → Contacts → Create property

| Property Name | Type | Description |
|---|---|---|
| `strtn_followup_cadence_day` | Number | Current cadence step: 0= new, 1/3/7/14/21/30 = sent |
| `strtn_last_followup_date` | Date | ISO date the last follow-up email was sent |
| `strtn_last_email_subject` | Single-line text | Subject line of the last sent email |
| `strtn_response_received` | Single-line text | "yes" if lead has replied to any email |
| `strtn_escalated` | Single-line text | "yes" if lead flagged for human review (stalled) |
| `strtn_lead_owner_email` | Single-line text | Client's email address (engine sends from this) |

**Note:** Without these properties, the engine reads/writes nothing to HubSpot and all contacts will appear as "new leads" every run.
