## Today's Most Important Priority

### 🔴 #1 PRIORITY: HubSpot Custom Properties (Ahmad Action Required)

This remains the single biggest product blocker. Without these 17 properties in HubSpot, the follow-up engine will fail silently on every contact — reads return nothing, writes save nowhere.

**Required (Engine won't work without these):**

| # | Property Name | Type | Description |
|---|---|---|---|
| 1 | `strtn_followup_cadence_day` | Number | Current day in cadence (1, 3, 7, 14, 21, 30). Default: 0. |
| 2 | `strtn_last_followup_date` | Date | ISO date of last follow-up email sent. |
| 3 | `strtn_last_email_subject` | Single-line text | Subject of the last email sent. |
| 4 | `strtn_response_received` | Single-checkbox | Yes/No. Default: No. |
| 5 | `strtn_escalated` | Single-checkbox | Yes/No. Default: No. |
| 6 | `strtn_lead_owner_email` | Single-line text | Client's email — engine sends from this account. |

**Recommended (Full feature set):**

| # | Property Name | Type | Description |
|---|---|---|---|
| 7 | `strtn_lead_status` | Single-line text | NEW / CONTACTED / FOLLOWING_UP / HOT / STALLED / CLOSED_WON / CLOSED_LOST |
| 8 | `strtn_lead_segment` | Single-line text | HOT / WARM / COLD / DORMANT |
| 9 | `strtn_lead_score` | Number | Score 1–10. Default: 5. |
| 10 | `strtn_last_contacted` | Date | Last contact date (any channel). |
| 11 | `strtn_follow_up_count` | Number | Emails sent. Default: 0. |
| 12 | `strtn_next_follow_up_date` | Date | Scheduled next follow-up. |
| 13 | `strtn_channel_preference` | Single-line text | WhatsApp / Email / Phone / Unknown |
| 14 | `strtn_last_reply_date` | Date | Date lead last replied. |
| 15 | `strtn_client_id` | Single-line text | Internal Qiyadon client ID. |
| 16 | `strtn_trial_lead` | Single-checkbox | Yes/No. Default: No. |
| 17 | `strtn_outreach_status` | Single-line text | PENDING / ACTIVE / REPLIED / STALLED / CONVERTED |

**Ahmad can create all 17 in ~5 minutes:**
HubSpot → Settings → Properties → Contacts → Create property (for each, exact name = case-sensitive)
