**🔴 CRITICAL — This is the #1 product blocker. Ahmad must create these in HubSpot before any client can be onboarded.**

The follow-up engine reads and writes these properties. If they don't exist in HubSpot, the engine will fail silently on every contact.

### REQUIRED (Engine won't work without these)

| # | Property Name | Type | Description | Values / Notes |
|---|---|---|---|---|
| 1 | `strtn_followup_cadence_day` | Number | Current day in the follow-up cadence (1, 3, 7, 14, 21, 30). Engine reads this to know which step to fire next. | Integer. Default: 0. |
| 2 | `strtn_last_followup_date` | Date | ISO date of the last follow-up email sent to this lead. Used to calculate days-since-last-contact. | ISO 8601 date format. |
| 3 | `strtn_last_email_subject` | Single-line text | Subject line of the last email sent. Useful for client reporting and debugging. | Free text, max 200 chars. |
| 4 | `strtn_response_received` | Single-checkbox (Yes/No) | Has this lead replied to any follow-up? Yes stops the cadence — lead is alive. | Checkbox. Values: Yes / No. Default: No. |
| 5 | `strtn_escalated` | Single-checkbox (Yes/No) | Has this lead been flagged for human review (stalled, needs decision)? | Checkbox. Values: Yes / No. Default: No. |
| 6 | `strtn_lead_owner_email` | Single-line text | The email address of the client (Qiyadon customer) whose pipeline this lead belongs to. Used by the engine to send from the right account. | Email format. |

### How to Create in HubSpot (Ahmad's Guide)

1. Log in to HubSpot → Settings → Properties
2. Select "Contact properties" (not Company or Deal)
3. Click "Create property"
4. For each property above, fill in:
   - **Property name:** exactly as listed (e.g., `strtn_followup_cadence_day`)
   - **Property type:** match the type column above
   - **Description:** copy from description column above
   - **Default value:** set as noted
5. For checkbox properties: Go to Properties → [property] → Settings → enable "Show checkbox as yes/no" or create as single-checkbox type
6. **Visibility:** Set to "Visible" for all properties (not hidden)
7. Repeat for all 17 properties

**⚠️ Property names ARE case-sensitive in HubSpot. Use exact names as listed above.**
