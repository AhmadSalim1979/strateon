### Key Design Decisions

1. **Graceful schema degradation**: All DB writes check for column existence and skip with warning if column not in schema. This allows running before migration.

2. **Execution mode detection priority**:
   - `X-Shadow-Mode: true` header (N8N parallel observer) → shadow
   - `event.source` starting with `shadow-` or `n8n-capture` → shadow
   - `payload.simulated === true` (shadow replay engine) → shadow
   - Otherwise → live

3. **Replay safety is entry-point, not handler-level**: `claimEventProcessing` is called at webhook receipt, not inside handlers. This rejects duplicates before any work is done.

4. **processed_by = event.source by default**: The event source field identifies which component emitted the event. Handlers can override with their own name.
