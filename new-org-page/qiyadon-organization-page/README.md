# Qiyadon Organization Page

This package contains a complete, static organization webpage for Qiyadon.

## Files

- `index.html` — full webpage markup
- `styles.css` — responsive styling
- `assets/qiyadon-logo.png` — supplied Qiyadon logo
- `assets/qiyadon-banner.png` — supplied Qiyadon banner

## Implementation

Upload the full folder to your web host, or copy the contents into the current Qiyadon site project. Keep the `assets` folder beside `index.html` and `styles.css` so the image paths continue to work.

The page links back to `https://qiyadon.com/` and key product sections.
