### Mode B Routing Logic
```
User → GPU shadow call → Quality check
  ├─ quality in GOOD_QUALITIES → return GPU response (source=GPU)
  ├─ quality = WORSE → return MiniMax (source=MiniMax, fallback_reason=quality_worse)
  ├─ status = timeout/error → return MiniMax (source=MiniMax, fallback_reason=failure/timeout)
  └─ malformed response → return MiniMax (source=MiniMax, fallback_reason=malformed)
```

GOOD_QUALITIES: COMPARABLE, COMPARABLE_CORRECT, COMPARABLE_CORRECT_REFUSAL, COMPARABLE_REFINED, COMPARABLE_DIFFERENT, PARTIALLY_COMPARABLE
