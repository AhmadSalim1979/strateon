### N8N Dependency Audit

**Location:** `/root/.openclaw/workspace/moosa-worker/src/n8n/client.js` — `fetchTaskPayload(taskId)`
- Calls N8N webhook with `{ task_id: "uuid" }`
- Returns `{ task_id, action_type, input_json, max_retries }`
- Used by worker loop in `/root/.openclaw/workspace/moosa-worker/src/core/loop.js`
- Triggered: every poll cycle, for tasks without `input_json` stored directly
- Non-blocking: failed N8N call → task fails, worker continues
- Action types with direct `input_json` (no N8N call): `thinking_loop`, `run_self_check_and_decide`, `bundle`, `code_assist_test`

**Criticality:** Medium — failure causes task failure but doesn't stop worker

**Replacement strategy:** New orchestration framework stores full payload in `jobs.payload` — N8N webhook never needed for new jobs
