### Key scoring facts (from code analysis)
- `consecutive_unhealthy >= 3` → +3 score
- `cooldownBlockCount >= 2` → +2 score (binary, not cbmm-weighted)
- `cu=2, cb=2` → score=2, priority=low, confidence=low
- `cu=3, cb=0` → score=3, generate_report/escalated, priority=medium, confidence=medium (positiveSignalCount=1)
- `cu=3, cb>=2` → score=5+, human_review tier (not generate_report)
- `confidence=high` requires: `score>=3 + no dedupe + positiveSignalCount>=2`
- `priority=high` for generate_report requires: `score>=5` OR `score>=3 with escalation`
