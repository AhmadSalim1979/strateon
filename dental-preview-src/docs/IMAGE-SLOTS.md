# Image slots

Generated from `image-manifest.json` (the source of truth). While a slot has no `src`, the site shows a styled placeholder at the same fixed aspect ratio, so adding images later causes no layout shift.

To add an image: put the files in `dental-preview-src/img/`, set `src` / `src_mobile` and `status` in the manifest, then rebuild. For wildcard slots (`team-portrait-*`, `service-*`) add a concrete entry per instance, e.g. `team-portrait-<clinician-slug>`, copying the wildcard entry. Illustrative samples must never be presented as real clinicians, patients or the real clinic.
