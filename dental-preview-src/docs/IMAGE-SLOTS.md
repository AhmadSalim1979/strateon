# Image slots

Generated by `build.mjs` from `image-manifest.json` (the source of truth); do not edit by hand. On the site, a slot without an image shows only its placeholder caption at the slot's fixed aspect ratio, so adding images later causes no layout shift. Slot IDs, ratios and sizes appear only here, never on the page.

To add an image: put the files in `dental-preview-src/img/`, set `src` / `src_mobile` and `status` in the manifest, then rebuild. For wildcard slots (`team-portrait-*`, `service-*`) add a concrete entry per instance, e.g. `team-portrait-<clinician-slug>`, copying the wildcard entry. Illustrative samples must never be presented as real clinicians, patients or the real clinic, and no generated likeness of Dr. Asif Niaz Arain may be used.
